# EasyFlow v1.4.1

This patch improves keyboard access, accessibility control names, and focus reliability while preserving rich text, reminders, image attachments, and the local workspace.

## Fixes

- Open the workspace by reopening the app or using Command-O, and open task details or Quick Notes through keyboard-accessible buttons.
- Use native action menus to reorder tasks, Steps, and notes, and attach Quick Notes without dragging.
- Keep keyboard navigation from being interrupted by pointer dismissal or hover-driven context replacement. Preserve keyboard ownership when changing Panel Side in Settings.
- Use Tab and Shift-Tab to leave multiline editors while preserving native selection, IME composition, formatting, and text accessibility.
- Clear the Quick Note composer after successful Return submission.
- Retire accessibility content and responders when panels close; transfer focus only to visible panels on the active Space.
- Preserve cross-Space restoration safeguards and avoid overriding a newer application choice on dismissal.
- Improve task, Step, note, effort, image, and reminder-setting labels and values.
- Keep reminder banners non-key/non-main, retire expired accessibility content, and intentionally focus the selected task when activated.
- Scope auxiliary-window close shortcuts to the key window.
- Remove the overlapping native dropdown indicator from circular action menus.

## Validation

- 153 tests in 25 suites; all prior tests retained.
- Debug and release-mode builds, local packaging/checksum, bundle/signature/privacy checks, and local data-integrity checks.
- No new system-wide Accessibility permission requirement or database migration.

The [accessibility audit](../ACCESSIBILITY_AUDIT.md) records the investigation, user publication authorization, local verification, and the interactive VoiceOver/Spaces checks that the agent could not automate. These checks are not represented as completed.
