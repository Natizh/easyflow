# EasyFlow v1.4.0

## New

- Internal non-native EasyFlow task reminder banners.
- Configurable reminder intervals.
- Temporary reminder pause.
- Per-task reminder exclusion.
- Reminder clicks open the exact target task.
- Rich-text shortcuts: Command-B, Command-I, Command-U, and Control-Command-H.
- Rounded text-marker highlights.

## Improvements and fixes

- More robust Main and Secondary panel lifecycle.
- Reliable behavior across macOS Spaces and fullscreen Spaces.
- Closing EasyFlow after changing Spaces no longer switches back to another Space.
- Cleaner Step action chevron.
- Corrected lower panel corners.
- Corrected reminder banner corners.
- Improved reminder Settings layout and custom controls.
